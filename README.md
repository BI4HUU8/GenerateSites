# GenerateSites

## Генератор header і body

Відкрийте `header_body.html` через локальний вебсервер або розмістіть папку на хостингу. Сторінка завантажує стартові параметри з `setting.json`.

1. Налаштуйте header: для логотипа оберіть зображення або текст; задайте URL іконки або текстову назву. Кольори, посилання та режими налаштовуються окремо. Air робить шапку прозорою поверх наступного блоку, Fixed закріплює її зверху. Поле номера телефону з'являється після ввімкнення опції показу телефону; розміщення можна вибрати перед або після меню.
2. У **«Посилання меню»** About і Contact ведуть до відповідних секцій головної сторінки. Кнопка **«Редагувати»** змінює посилання або відкриває редактор пов’язаної сторінки. У **«Блоки body»** сторінки показані окремими рядками й за замовчуванням згорнуті; натисніть назву, щоб розгорнути поля сторінки. Блоки також згорнуті спочатку; натисніть їхню назву, щоб відкрити налаштування. **«Додати блок»** додає `hero`, `about`, `contact`, `faq` або `features` до відкритої сторінки. У FAQ задайте заголовок, окремо запитання та відповіді та за потреби додайте або видаліть питання. У Contact можна заповнити телефон, email, адресу та графік роботи. **«Додати сторінку»** автоматично додає посилання в меню; сторінки зі старих налаштувань без посилання також додаються автоматично. Перед видаленням сторінки, блоку чи посилання з'являється запит на підтвердження.
3. Натисніть **«Зберегти JSON і згенерувати HTML»**, щоб зберегти всі налаштування у cookie `setting` на 30 днів та сформувати цілісний HTML сайту.
У блоці **«Налаштування SEO GEO»** задайте title, description, ключові слова, canonical URL, robots, Open Graph дані та геолокацію: регіон, населений пункт, координати й мову. Ці метадані автоматично додаються в `<head>` згенерованого HTML.
4. Скопіюйте код або завантажте файл `site.html`. Кнопка **«Завантажити JSON налаштувань»** зберігає поточну конфігурацію як `setting.json`; **«Завантажити налаштування»** відкриває локальний JSON-файл і відновлює його в редакторі. Якщо сторінок кілька, у згенерованому файлі з'явиться список для перемикання між ними, а slug стане частиною hash-адреси (`#about`). У налаштуваннях замініть прикладні URL зображень на свої.

Збереження cookie потребує дозволених cookie у браузері. Загальний ліміт налаштувань у cookie — приблизно 3,8 КБ.
Згенерована шапка та блоки body адаптуються до мобільних екранів. Сторінку слід запускати через локальний вебсервер, щоб браузер міг завантажити `setting.json`.
